#### **Practicals Overview**



###### **Lab Practical 1: Campus News Webpage**



Objective: Recreate a university news webpage using pure HTML.



**Key HTML Concepts:**



* Document layout (<!DOCTYPE html>, <html>, <head>, <body>)
* Headings (<h1> to <h3>)
* Text formatting \& breaks (<p>, <br>, <hr>)
* Lists (Unordered <ul> \& Ordered <ol>)
* Tables with borders (<table>, <tr>, <th>, <td>)
* Image embedding (<img>)
* Hyperlinks (<a>)
